How to import it
  1. In Shopify, go to Products and click Import.
  2. Choose the downloaded file.
  3. Tick Overwrite products with matching handles. Columns not in the file keep their current values.
  4. Click Upload and preview, check the changes, then Import products.

The file holds only the products and columns that changed. It leaves images and inventory alone.
